# Apparatus (SonoAdapt)

This folder contains the source code for the SonoAdapt's Android application used in the summative study.

## Source Code Location

Since the project is built as an Android application, the core source code is nested within the app's directory structure. You can find the main code files here:

**Path:** `app/src/main/java/com/meta/wearable/dat/externalsampleapps/cameraaccess`

## Setup Instructions

To build or run the application:
1. Open the project in Android Studio.
2. In the root directory of this project, you will find a `local.properties` file.
3. Replace the placeholder keys (`<YOUR_GITHUB_TOKEN>`, `<YOUR_GEMINI_API_KEY>`) with your own actual API keys to enable functionality.
4. Sync the project with Gradle files and build.

## Note on Project Size
To keep the submission size manageable, generated build output folders (like `app/build/`) have been removed.
