scene_memory
  Return an UPDATED narrative that folds the CURRENT frame into that prior memory.
  This is a MEMORY OF THE PAST, not a caption of the present frame. The other
  sections above (task_context, sound_sources, social_context) already describe
  NOW; do NOT merely restate them here. If your scene_memory could be swapped
  with task_context.activity_description without loss, it is WRONG.

  Build it as a running account of how the situation reached the present, tracking
  four threads over time:

  1. TASK SEQUENCE — the ordered actions/events that led here, as a sequence.
     - If the current observation CONTINUES the ongoing task, EXTEND that task's
       sequence with the new action (e.g. "...then opened the refrigerator, then
       sat down at the table").
     - If the owner has clearly STARTED A DIFFERENT task, close the previous one
       and begin a new sequence, keeping the earlier tasks as prior history.
     - Preserve concrete past actions even when their objects are no longer in
       view — earlier steps do not disappear just because the frame moved on.
  2. SOCIAL HISTORY — who has been present, and any changes (someone arrived/left,
     conversation started/stopped). Note only changes and their timing, not a
     per-frame restatement.
  3. SOUND HISTORY — notable sounds/acoustic conditions observed over time and how
     they changed (e.g. "quiet throughout, with intermittent speech"). Note
     changes, not the current frame's audio alone.
  4. PRESENT STATE — end with one short clause on what is happening now, placed as
     the latest point in the narrative.

  Rules:
  - If no RECENT MEMORY was provided, write the first narrative from this frame
    alone (mostly PRESENT STATE, little history yet).
  - Prefer CONTINUITY: an ongoing activity is not reclassified just because a
    defining object left the frame; only start a new task sequence on clear
    positive evidence of a real transition.
  - Keep it to 3–5 sentences. As history grows, COMPRESS older steps (summarize
    completed tasks in a clause) while keeping the recent sequence detailed.
  - Write past events in past tense and the present in present tense, so the
    reader can tell history from now.

  Example of the intended style (kitchen → meal):
    "The device owner and one other person were in a domestic kitchen preparing a
    meal. The owner took tableware from the cupboards and drawers and looked in
    the refrigerator, then sat down at the table across from the other person.
    The two have been in casual conversation throughout, and are still talking as
    they now eat."
