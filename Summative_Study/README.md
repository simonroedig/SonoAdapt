# SonoAdapt Summative Study

This folder contains all materials, data, and results for the summative study of the thesis. 

## Structure
- **in_study_audiofiles/**: Audio files used during the study sessions.
- **phones/**: Regarding the created phone devices used in the study.
- **results/**: Collected data, analysis scripts, and generated plots.
- **study_design/**: Documentation on how the study was structured and counterbalanced.
